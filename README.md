# Watch Time Window 紹介サイト

スクリーンショット付き紹介ページとプライバシーポリシー。外部ライブラリ・ビルド処理は不要です。

- index.html: 紹介ページ
- privacy.html: プライバシーポリシー
- styles.css: 共通スタイル（モバイル対応）
- assets/: アイコンと紹介画像

GitHub Pages は main ブランチのルートから公開します。
ストア公開後は index.html の公開準備中表示をストアへのリンクに変更してください。

コミットは Conventional Commits 形式で概要・本文を日本語にします。
